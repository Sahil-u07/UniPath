# UniPath - Your AI-Powered Career Assistant

🚀 **Live Demo:** [https://unipath-ai-career.netlify.app/](https://unipath-ai-career.netlify.app/)

## About

Your AI-powered assistant for job search, resume optimization, mock interviews, and career growth.

## Features

- 📝 AI-Powered Resume Builder
- 💼 AI Cover Letter Generator
- 🎯 Mock Interview Practice
- 📊 Industry Insights
- 🤖 Powered by Google Gemini AI

## Tech Stack

- **Framework:** Next.js 16
- **Authentication:** Clerk
- **Database:** PostgreSQL (Neon)
- **Styling:** Tailwind CSS
- **AI:** Google Gemini API
- **Deployment:** Netlify
